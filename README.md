# CRT ASCII Tileset for MMapper

A CRT-inspired ASCII-style map tileset for [MMapper](https://github.com/MUME/MMapper), the mapping client for MUME.

## Installation

1. Download this repository using **Code → Download ZIP** and extract it.
2. Locate the extracted `pixmaps` directory containing the tileset PNG images.
3. Configure MMapper to use this custom `pixmaps` directory according to the graphics/tileset settings of your MMapper version.
4. Restart or reload the map graphics if required.

Keep the original PNG filenames unchanged; MMapper uses them to identify map features.

## Contents

- `pixmaps/` — 130 PNG assets for terrain, trails, exits, doors, and map symbols.
