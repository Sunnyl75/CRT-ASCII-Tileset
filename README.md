# CRT ASCII Tileset for MMapper

A CRT-inspired ASCII-style map tileset for [MMapper](https://github.com/MUME/MMapper), the mapping client for MUME.

## Installation

1. Download this repository using **Code → Download ZIP** and extract it.
2. Locate the extracted `pixmaps` directory. It contains the tileset PNG images.
3. In MMapper, choose the graphics/tileset configuration for a custom set of pixmaps and point it at this `pixmaps` directory, following the instructions for your MMapper version.
4. Restart or reload map graphics if required.

Keep all original filenames intact, as they are used to identify individual map features.

## Contents

- `pixmaps/` — 130 PNG assets for terrain, trails, exits, doors and other map symbols.
